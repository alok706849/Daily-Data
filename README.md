# NSE Intraday Top 5 Big-Move Scanner

Personal-use Streamlit app for ranking potential intraday momentum setups.

### Features
- Top 5 ranked setups
- Signal strength: Moderate / Strong / Very Strong
- BUY / SELL
- Entry, initial SL, Target 1, Target 2, RR
- ATR-based trailing SL rules
- EMA20/EMA50, VWAP, breakout/breakdown, relative volume, RSI

### Free deployment
Upload this repository to GitHub and deploy `app.py` on Streamlit Community Cloud. No paid API key is required.

### Important
Free Yahoo Finance data can be delayed, incomplete, rate-limited, or unavailable. This app does not guarantee that a stock will move. Use paper trading/backtesting before risking capital and confirm live prices with your broker.
